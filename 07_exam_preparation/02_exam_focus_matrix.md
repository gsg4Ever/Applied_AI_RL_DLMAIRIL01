# Exam focus matrix

This matrix describes what to explain from the book. It **does not predict exam topics or assign unsupported exam priorities**. Set your own priority in the last column.

| Course-book section | Explain from memory | My priority |
|---|---|---|
| [[01_unit_1_introduction_to_reinforcement_learning/01_understanding_reinforcement_learning|1.1 Understanding Reinforcement Learning]] | Reinforcement learning optimizes sequential decisions by learning from agent-environment interaction; dynamic programming supplies value, Q-factor and Bellman principles, while learning and approximation address explicit-model and table-size obstacles. |  |
| [[01_unit_1_introduction_to_reinforcement_learning/02_components_of_reinforcement_learning_systems|1.2 Components of Reinforcement Learning Systems]] | Policy evaluation learns returns or bootstrapped values; Q-learning and SARSA turn these ideas into control, while continuing exploration, replay and neural-network approximation address data and representation limitations. |  |
| [[02_unit_2_dynamic_programming_and_markov_decision_processes/01_introduction_to_sequential_decision_making|2.1 Introduction to Sequential Decision Making]] | Dynamic programming exploits the fact that optimal continuations can be solved as smaller subproblems, avoiding repeated enumeration of complete decision sequences. |  |
| [[02_unit_2_dynamic_programming_and_markov_decision_processes/02_dynamic_programming|2.2 Dynamic Programming]] | A dynamic-programming model must specify its information, admissible decisions, transitions, lifetime and cost aggregation; the Markov property permits state-based recursion, and a fixed MDP policy induces a Markov chain. |  |
| [[02_unit_2_dynamic_programming_and_markov_decision_processes/03_bellmans_equation|2.3 Bellman's Equation]] | Bellman's equation combines a current decision with optimal continuation; backward induction, value iteration and policy iteration solve it in different ways, but large state spaces can still make exact optimization impractical. |  |
| [[02_unit_2_dynamic_programming_and_markov_decision_processes/04_general_utility_functions|2.4 General Utility Functions]] | Utility incorporates decision-maker valuation and risk attitude; changing the cost-accrual criterion can change the optimal policy even when the underlying routes and transitions remain unchanged. |  |
| [[03_unit_3_bandit_problems/01_one_armed_bandit_problem|3.1 The One-Armed Bandit Problem]] | Bandit decisions must earn reward and gather information simultaneously; regret measures the reward sacrificed relative to the best-known-mean choice, and insufficient continued sampling can lock a policy into an inferior source. |  |
| [[03_unit_3_bandit_problems/02_multiple_arm_bandit_problem|3.2 The Multiple Arm Bandit Problem]] | Effective bandit policies combine current reward estimates with continuing exploration; epsilon-greedy and softmax force exploration, gradient methods adjust relative preferences, and uncertainty indices such as UCB1 favor both promising and under-sampled arms. |  |
| [[04_unit_4_q_learning/01_q_learning_and_time_difference_learning|4.1 Q-Learning and Time-difference Learning]] | Q-learning replaces model-based expectations with sampled TD targets; SARSA changes the target to the next action selected by the current policy, producing the on-policy versus off-policy distinction. |  |
| [[04_unit_4_q_learning/02_reinforcement_learning_with_neural_networks_and_deep_q_learning|4.2 Reinforcement Learning with Neural Networks and Deep Q-Learning]] | A DQN approximates Q-values with learned parameters and features, avoiding independent storage of every state-action value; its bootstrapped, evolving target creates stability problems addressed by later methods. |  |
| [[04_unit_4_q_learning/03_experience_replay|4.3 Experience Replay]] | Experience replay stores and reuses state-action-reward-successor tuples; randomized sampling reduces temporal correlations, and prioritized replay concentrates training on experiences expected to improve predictions most. |  |
| [[04_unit_4_q_learning/04_double_q_learning|4.4 Double Q-Learning]] | Double DQN separates action selection by the online network from evaluation by the target network, while periodic target copying independently reduces rapid feedback in bootstrapped targets. |  |
| [[04_unit_4_q_learning/05_delayed_sparse_rewards_and_hierarchical_learning|4.5 Delayed Sparse Rewards and Hierarchical Learning]] | Sparse delayed rewards make useful feedback difficult to obtain; goal-conditioned values represent different tasks, and hierarchical learning separates selecting goals from acting to accomplish them. |  |
| [[04_unit_4_q_learning/06_value_vs_policy_based_learning|4.6 Value- vs. Policy-Based Learning]] | Value-based learning derives a policy from learned action values; policy-based learning directly optimizes policy parameters with gradient ascent, and REINFORCE uses observed returns to estimate the policy-gradient update. |  |
| [[04_unit_4_q_learning/07_actor_critic_learning|4.7 Actor Critic Learning]] | Actor-critic combines direct policy updates with learned value feedback; advantage centers action quality relative to state value, and the source's synchronous, asynchronous, entropy and surrogate-objective extensions address efficiency, variance and stability. |  |
| [[05_unit_5_reinforcement_learning_approaches/01_model_free_learning|5.1 Model-Free Learning]] | Model-free learning uses experience directly: Monte Carlo prediction averages complete episode returns, while TD learns from reward-plus-continuation estimates and can support stepwise control. |  |
| [[05_unit_5_reinforcement_learning_approaches/02_model_based_learning|5.2 Model-Based Learning]] | Model-based learning estimates rewards and transitions for planning; Dyna reuses learned information, MCTS limits search, and MBPO limits imagined rollout length to reduce compounded model error. |  |
| [[05_unit_5_reinforcement_learning_approaches/03_exploration_vs_exploitation|5.3 Exploration vs. Exploitation]] | Exploration trades current reward against useful information: epsilon-greedy and Boltzmann randomize actions, posterior/bootstrapped methods represent uncertainty, curiosity rewards controllable learning, and model-based methods use known-state tests, optimism or prioritized updates. |  |
| [[06_worked_appendices/a_treasure_seeking|Appendix A: Treasure Seeking]] | The source treasure program implements backward induction using a six-entry action-value workspace and growing optimal-value/policy arrays, with output indexed by days remaining. |  |
| [[06_worked_appendices/b_towers_of_hanoi|Appendix B: Towers of Hanoi]] | The Hanoi implementation converts legal disk moves into a deterministic shortest-path problem, enumerates configurations by integer indices, and follows the converged successor policy to reconstruct the published minimum-move path. |  |
| [[06_worked_appendices/c_switchover_queue_control|Appendix C: Switchover Queue Control]] | The queue example builds a cost-minimizing MDP at event epochs, derives transitions from exponential races, and uses value iteration to produce next-queue policy matrices with boundary-dependent, potentially nonmonotonic decisions. |  |
| [[06_worked_appendices/d_cake_eating|Appendix D: Cake Eating]] | Cake eating is a continuous-state/action finite-horizon allocation problem; backward induction balances marginal utilities and yields the source's geometric-denominator consumption rule for logarithmic utility. |  |
| [[06_worked_appendices/e_q_learning_treasure_seeking|Appendix E: Q Learning Treasure Seeking]] | The source treasure Q-learner learns from uniformly random simulated episodes, uses terminal-aware targets and reciprocal visit counts, and recovers the exact policy while its published value estimates remain approximate. |  |
