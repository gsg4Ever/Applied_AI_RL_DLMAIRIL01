# START HERE - DLMAIRIL01 Learning Vault

## Scope

This vault summarizes the supplied **Reinforcement Learning** course book, **DLMAIRIL01**, version **001-2024-0328**, in English. Subject matter, worked examples and named algorithms come only from this book. The wording is condensed and paraphrased, not a verbatim reproduction. Flashcards, recall questions, checklists and cheat sheets are study formats for the same material.

## Start learning

1. Open [[00_COURSE_COVERAGE_MAP]].
2. Read the unit overview and then its numbered section notes.
3. Study the original figures and tables **where they appear in the explanation**.
4. Answer each note's folded recall questions before revealing the answers.
5. Review [[08_Flashcards/README|Flashcards]] and [[08_CheatSheets/README|Cheat sheets]].
6. Record your progress in [[07_exam_preparation/01_deep_learning_workflow]].

## Obsidian study features

The same installed **Spaced Repetition** and **PDF++** plugin files as in the reference vault are provided, with fresh flashcard scheduling and without copied personal history. If Obsidian is in Restricted Mode, enable community plugins in Settings, then enable **Spaced Repetition** and **PDF++**. Reload Obsidian if it was open during creation.

Cards use the reference vault's `Question::Answer` syntax and the `#flashcards` tag hierarchy. Standard Obsidian links, math, callouts and checklists work without these plugins. All reviews start unscheduled; note confidence is intentionally blank.
