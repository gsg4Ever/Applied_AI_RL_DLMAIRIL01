# Unit 5: Reinforcement Learning Approaches

## Learning goals from the course book

- Explain model-free and model-based reinforcement learning.
- Explain the exploration-exploitation dilemma.
- Describe the course-book strategies for this dilemma in both approach families.

## Introduction and connections

A fully known decision model permits planning with value or policy iteration, but realistic models can be unknown or too large. Model-free methods learn values or behavior directly; model-based methods learn environment dynamics and rewards before planning. Both must balance familiar actions with informative exploration.
