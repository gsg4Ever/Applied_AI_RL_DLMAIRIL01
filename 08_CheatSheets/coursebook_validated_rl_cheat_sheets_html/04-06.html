Core explanation

Value-based learning derives a policy from learned action values; policy-based learning directly optimizes policy parameters with gradient ascent, and REINFORCE uses observed returns to estimate the policy-gradient update.

Key terms

TermMeaning
Implicit policyAn action rule derived from learned values.
Stochastic policyAction probabilities conditioned on the current state.

Objective JExpected return to maximize.
Gradient ascentUpdate parameters in a direction increasing the objective.
REINFORCEA policy-gradient update using sampled future returns.

Source-book example

The source REINFORCE procedure samples states, actions and rewards under one policy, then uses the future discounted reward from each visited step to weight the policy update. The same sampled trajectory supplies several step-specific returns, rather than one fixed label for every action.

Active recall

Answer before expanding. Open the answers before printing to include them.

How does value-based learning obtain a policy?

Choose actions with the highest learned Q-values.

What does policy-based learning optimize directly?

Parameters of the action-selection policy.

How do deterministic and stochastic policies differ?

One chooses a fixed action for a state; the other assigns action probabilities.

What does the policy objective J represent?

Expected cumulative discounted reward under the policy.

Why does the parameter update use gradient ascent?

The objective is to maximize expected return.

What weights the source policy-gradient expression?

The action's value under the current policy.

What does REINFORCE substitute for that action value?

The observed future discounted return from the trajectory.

Why is the presented policy-gradient approach on-policy?

Its samples come from the policy currently being evaluated and improved.
