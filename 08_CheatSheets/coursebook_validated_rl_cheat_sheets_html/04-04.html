Core explanation

Double DQN separates action selection by the online network from evaluation by the target network, while periodic target copying independently reduces rapid feedback in bootstrapped targets.

Key terms

TermMeaning
Online networkThe trained network used for current action-value estimates.
Target networkA periodically refreshed copy used to calculate training targets.
Moving-target feedbackPredictions and the targets built from them change together.
Maximization biasSelecting a largest noisy estimate can favor estimation error.
Double DQNOnline action selection combined with target-network evaluation.

Source-book example

The source considers actions whose true Q-values may be equal but whose estimates fluctuate. Choosing the largest estimate and treating it as its own evaluation can select an upward error. Double DQN uses one network to choose and the other to evaluate the selected action.

Active recall

Answer before expanding. Open the answers before printing to include them.

Why use a target-network copy?

To make the bootstrapped training target change less rapidly.

What target refresh interval does the cited original DQN example report?

Ten thousand interactions.

What causes maximization bias?

The same noisy estimates both select the largest action value and evaluate it.

Which network selects the next action in Double DQN?

The online network.

Which network evaluates that selected action?

The target network.

Are target stabilization and Double Q selection/evaluation separation identical?

No; they address moving-target instability and maximization bias respectively.
