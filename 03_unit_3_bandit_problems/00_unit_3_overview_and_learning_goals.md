# Unit 3: Bandit Problems

## Learning goals from the course book

- Define a bandit problem and its place within sequential decision processes.
- Explain epsilon-greedy, softmax, gradient and index policies.

## Introduction and connections

The opening clinical-trial example contrasts learning which treatment is best with giving the currently preferred treatment. Clinical equipoise describes uncertainty about comparative treatment merit. The bandit formalism makes this learning-versus-performance tension explicit; it is a study example, not a clinical recommendation.
